# Furniture Ecommerce Full Stack Project

This is a comprehensive full-stack ecommerce application for furniture.

## Project Structure
- **furniture-react**: Frontend built with React and Vite.
- **furniture_backend**: Backend built with Django.

## Features
- Interactive 3D furniture visualizer.
- Secure user authentication.
- Shopping cart and order management.
- Real-time notifications.
- Admin dashboard for product management.
