# 🛋️ The Urban Karigar | Furniture & Interiors

> **Where Dreams Meet Craftsmanship**

The Urban Karigar is a premium e-commerce platform and digital showcase for high-quality furniture, modular kitchens, and bespoke interior design solutions. Designed with a sleek, modern aesthetic, this application provides a seamless experience for customers to browse, customize, and enquire about their dream furniture.

---

## ✨ Key Features

### 🛒 E-Commerce & Product Management
- **Extensive Catalog**: Browse multiple categories including Sofa Sets, Beds, Wardrobes, and more.
- **Dynamic Category Filtering**: Easily filter products by category or use the advanced search.
- **Detailed Product Pages**: High-resolution image galleries, detailed specifications, and price comparisons.
- **Cart & Wishlist**: Manage your favorite items and prepare for checkout.

### 📐 Specialized Services
- **Modular Kitchens**: Dedicated section for L-Shape, U-Shape, Island, and Straight kitchen designs.
- **Interior Projects**: A portfolio showcase of completed Home, Hotel, and Office interior projects.
- **Room Visualizer**: Interactive tool for visualising furniture in different room settings.

### 🛠️ Admin Dashboard
- **Full Inventory Control**: Add, update, or remove products, categories, and projects.
- **Order Management**: Track and manage customer orders and payment statuses.
- **Analytics**: Monitor business performance through a central dashboard.
- **Content Management**: Update carousel images, business settings, and marketing banners.

### 📱 Connectivity
- **WhatsApp Integration**: Instant enquiry button for every product.
- **Secure Authentication**: User accounts with order history and profile management.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.

---

## 🚀 Tech Stack

- **Frontend**: React 19, Vite, React Router 7
- **Styling**: Vanilla CSS (Custom UI Components)
- **State Management**: React Context API (Auth, Data, Cart, Order, Wishlist)
- **API Communication**: Axios
- **Backend**: Django (REST Framework)

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd furniture-react
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a `.env` file in the root and add your API base URL:
   ```env
   VITE_API_BASE_URL=http://your-django-api-url/api
   ```
5. Start the development server:
   ```bash
   npm run dev
   ```

### Building for Production
```bash
npm run build
```
